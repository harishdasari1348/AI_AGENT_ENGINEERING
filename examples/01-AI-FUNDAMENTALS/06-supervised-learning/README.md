# Supervised Learning

Companion code for [Supervised Learning](../../../docs/01-AI-FUNDAMENTALS/01-introduction-to-artificial-intelligence/06-supervised-learning.md).

## Quick start

```bash
python -m venv .venv
# Windows (PowerShell): .venv\Scripts\Activate.ps1
# macOS / Linux:        source .venv/bin/activate
pip install -r requirements.txt
jupyter notebook supervised_learning.ipynb
```

## Run the tests

```bash
python -m pytest
```
